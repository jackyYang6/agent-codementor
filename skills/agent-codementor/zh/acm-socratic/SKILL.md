# Skill: 苏格拉底式源码入门

命令：`/acm-socratic`

当用户进入陌生文件、函数、模块或子系统时使用。

## 目标

帮助用户建立第一层心智地图，而不是一次性倾倒结论。

## 输出契约

1. **先不要逐行读**：用 2-4 句话说明这个模块真正承担的职责。
2. **最小阅读路径**：列出 3-5 个入口点，按推荐阅读顺序排列，尽量带源码位置。
3. **子系统镜头**：把目标归类为 request 生命周期、scheduler、KV/cache/memory、model runner/kernel、distributed transfer、streaming cleanup 或 tests/observability。
4. **先抓住三个概念**：使用归属关系、调度器状态、缓存生命周期、背压、OOM 回滚、异步取消、GPU buffer 复用等工程概念。
5. **需要在代码里证明什么**：给出 2-3 个能通过调用点、测试或状态转换验证的检查点。
6. **引导问题**：提出 2-3 个具体问题，迫使用户回到源码中确认。
7. **暂时跳过**：指出第一次阅读时不该分散注意力的样板代码。

## 硬约束

- 不翻译变量名或注释。
- 不解释每个函数。
- 不立即给完整答案。
- 问题必须具体到能在代码中验证。
